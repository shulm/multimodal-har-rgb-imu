# Limitations

Six development subjects and eight selected activities cannot establish robustness
across people, environments or the full 27-action dataset. Historical evaluation
exposure prevents a pristine final-test interpretation. Three seeds do not multiply
the number of independent recordings. Selection and descriptive calibration reuse
development evidence; neither OOD safety nor new-person coverage is guaranteed.

Throw can be accepted as wave. Neighbor agreement can reinforce the same error.
Deployment precision depends on unknown prevalence and reviewed sampling, not just
accepted-known accuracy. Missing modalities reduce available evidence; explicit
fallback does not promise preserved accuracy. Preprocessing assumes completed clips,
not live synchronization or streaming boundaries. Runtime error messages and optional
logs should be handled as local diagnostic content, not published indiscriminately.

The package contains no training pipeline, deployed service, automated monitoring,
model download, or reproducible full-data benchmark. Synthetic success shows only
implementation properties. Real evaluation needs separately permitted inputs and
compatible trusted artifacts. No model artifacts are cleared for redistribution.
